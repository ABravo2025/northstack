# Informe de hardening — SOC 2 / ISO 27001:2022 / ISO 27701 — Producción

- **Fecha:** 2026-11-06
- **Alcance:** producción (`origin/main` @ `76aaf6e8`, `app.joinnorthstack.com`, `joinnorthstack.com`)
- **Método:** análisis estático del código en `origin/main`, `npm audit` sobre el lockfile de `origin/main`, y lectura de headers HTTP en vivo (solo GET/HEAD).
- **Datos de producción:** no se leyó ni se modificó ningún dato durante esta auditoría.
- **Aclaración:** SOC 2 e ISO 27001/27701 se certifican con un auditor externo y requieren controles organizativos (políticas, gestión de riesgos, revisiones de acceso, proveedores). Este informe cubre el **hardening técnico** y señala los huecos documentales; no reemplaza la auditoría.

## Controles ya verificados como sólidos (no re-auditar)

scrypt+salt+timingSafeEqual para contraseñas; 2FA obligatorio para owner / billing / staff (`authService.ts:160-167`); cifrado AES-256-GCM de campos sensibles; aislamiento de tenant (~90 servicios); firma HMAC de webhooks entrantes; Helmet en la API (`src/app.ts:109`, CSP/HSTS/nosniff confirmados en vivo en `/health`); rate limiting con Upstash; retención del Activity Log por plan (cron diario); purga de tenant (`tenantPurgeService.ts`); `.env` nunca commiteado.

## Huecos documentales (no técnicos) — necesarios para SOC 2 / ISO

Política de seguridad de la información y alcance del SGSI · Registro de riesgos · Declaración de Aplicabilidad (SoA) · Inventario de activos y registro de actividades de tratamiento (RoPA) · Lista de subprocesadores (Vercel, Neon, Upstash, proveedor de email, Stripe, Mercado Pago, Dodo, Google) · Plan de respuesta a incidentes y notificación de brechas · Revisión trimestral de accesos (GitHub, Vercel, Neon, Admin) · Política de retención y eliminación · Plan de continuidad.

## Riesgo teórico no confirmado

- Que `main` no tenga protección de rama (no verificado: `gh` sin autenticar).
- Que la SPA tenga algún XSS explotable: no se encontró ninguno (auditoría 2026-09-10); los headers de SEC-H02 son defensa en profundidad.
